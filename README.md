# Anteiku WIKI

**Оффлайн-версия сайта Антейку в игре Broken Ranks.**

Приложение для Android, внутри которого лежит полная копия сайта Антейку
([anteikutaern.at.ua](https://anteikutaern.at.ua)) — вики, гайды и статьи
по игре. Всё уже внутри приложения, интернет не нужен.

## Возможности

- 📖 Полная оффлайн-копия сайта — всё хранится внутри приложения
- 📶 Работает без интернета
- 📱 Простой просмотр статей прямо в приложении
- ⚡ Открывается мгновенно

## Установка

1. Скачать APK из раздела **Releases**.
2. Разрешить установку из неизвестных источников, если Android попросит.
3. Установить и открыть.

> Если раньше стояла debug-версия, перед установкой удалите её — подписи
> разные, обновление поверх не встанет. Данные не теряются: всё содержимое
> лежит внутри приложения.

## Примечание

Неофициальное фанатское приложение. Не связано с разработчиками игры
Broken Ranks. Все материалы сайта принадлежат их авторам.
